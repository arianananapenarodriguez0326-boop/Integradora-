# UniBot - Sistema Asesor Académico

## Descripción

UniBot es un sistema de asesoría académica para estudiantes de primer año. Su objetivo es ayudar a los estudiantes con consultas académicas y técnicas, teniendo en cuenta la carrera a la que pertenecen y los temas permitidos para la misma.

## Proyecto

Este proyecto corresponde a la Tarea Integradora de la asignatura Algoritmos y Programación I.

## Metodología

Para el desarrollo del proyecto se escogió Scrum como marco de trabajo ágil. El proyecto se desarrollará de manera incremental mediante diferentes Sprints.

## Roles del sistema

- **Estudiante:** realiza consultas académicas y técnicas mediante UniBot.
- **Administrador:** gestiona los estudiantes, los temas permitidos y las sesiones.

## Sprints

- **Sprint 1:** Requisitos y planificación.
- **Sprint 2:** Prototipo inicial.
- **Sprint 3:** Programación orientada a objetos.
- **Sprint 4:** Gestión de acceso y sesiones.
- **Sprint 5:** Integración de la IA.

## Estado del proyecto

Actualmente el proyecto se encuentra en la primera fase, correspondiente al análisis, definición de requisitos y planificación.
